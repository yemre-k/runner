Concept Guide

What does this run teach?

ActorThe person, role, or external system that uses the system. Question: who uses it?
Use CaseA goal or action the actor wants to achieve inside the system.
User StoryAs a role, I want an action, so that I gain a benefit.
includeA mandatory dependency. Always runs whenever the base use case runs.
extendOptional or conditional behavior. Added only in certain situations.
BoundaryActors sit outside the system; use cases sit inside the system boundary.
